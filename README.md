# Breast-Cancer-Detection-using-Hybrid-ViT-and-VLMs.

1) Binary Classification using Vision Transformer four variants on two datasets ie., Multispectral dataset and Histopathology dataset.
2) The Vision Transformer models were trained and comparative analysis were performed on two train-validation-splits ie., 70:15:15 and 80:10:10 splits.
3) This was done to let model learn weights, best weights selection can be done and final unbiased evaluation can be performed.
4) Then, attention maps were extracted which highlighted image regions and lesion boundaries.
5) Attention maps were feeded into Vision Language Model to interpret human like explaination imcluding color, textures, boundaries, causes and effects, precautions etc.
